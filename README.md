# Aionis Solutions — Landing Page

Landing page institucional da **Aionis Solutions**, empresa de soluções e consultoria em TI.

## Visão geral

Página única (single page), responsiva e sem dependências de build. Feita com HTML, CSS e JavaScript puros.

## Estrutura

| Arquivo | Descrição |
|---------|-----------|
| `index.html` | Marcação e conteúdo da página |
| `styles.css` | Estilos, identidade visual e responsividade |
| `script.js` | Menu mobile e formulário de contato |
| `Aionis logo.jpeg` | Logotipo da marca |

## Seções

- **Header** com logo, navegação e botão "Fale Conosco"
- **Hero** com CTA "Solicite um orçamento"
- **Soluções** (TI personalizadas, soluções prontas, automação, consultoria)
- **Por que a Aionis** (diferenciais)
- **Contato** (formulário + informações)
- **Footer** com redes sociais e direitos autorais

## Identidade visual

- Paleta: azul marinho/royal para textos e detalhes, gradiente azul → ciano → verde-turquesa para destaques
- Tipografia: Space Grotesk (títulos) + Inter (corpo)
- Estilo clean, minimalista e corporativo

## Como executar

Basta abrir o arquivo `index.html` em qualquer navegador moderno.
